# PTVD - FFmpeg Видеопроцессор

> **Языки / Languages:** [简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [Русский](README.ru.md) | [Deutsch](README.de.md) | [Français](README.fr.md)

Инструмент для обработки видео в браузере на основе FFmpeg.wasm. Все вычисления происходят локально — без серверных мощностей.

## Возможности

- **Полный фронтенд** — На базе FFmpeg.wasm, вся обработка видео выполняется в браузере. Без бэкенда.
- **Многофайловая конкатенация** — Загрузка нескольких видео с автоматической генерацией concat filter команд.
- **101 пресет** — 6 категорий: монтаж, фильтры, аудио, водяные знаки, субтитры, эффекты.
- **Разбор команд** — Каждый параметр команды сопровождается описанием и пометкой редактируемых частей.
- **Многоязычность** — Китайский, английский, японский, русский, немецкий, французский.
- **Умная загрузка CDN** — FFmpeg загружается с CDN при первом визите, затем из кэша IndexedDB.
- **Изоляция Cross-Origin** — Автоматическая настройка COOP/COEP для SharedArrayBuffer.
- **Фильтр безопасности** — Автоматическая блокировка опасных команд (удаление файлов, сетевые запросы).

## Быстрый старт

### Требования

- Node.js >= 18
- npm >= 9

### Установка и запуск

```bash
# Установка зависимостей
npm install

# Дев-сервер
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр
npm run preview
```

Дев-сервер запускается на `http://localhost:5173/` по умолчанию.

## Развертывание

### Cloudflare Pages (Рекомендуется)

1. Сборка: `npm run build`
2. Загрузите каталог `dist/` в Cloudflare Pages
3. Или используйте Wrangler CLI:

```bash
npx wrangler pages deploy dist --project-name ptvd
```

> **Примечание:** `functions/middleware.js` автоматически внедряет заголовки COOP/COEP для поддержки SharedArrayBuffer.

### Другие статические хостинги

Убедитесь, что сервер устанавливает следующие HTTP-заголовки:

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

## Технологии

- **Фреймворк:** React 18 + TypeScript
- **Сборка:** Vite 5
- **Движок:** FFmpeg.wasm 0.12.6
- **Управление состоянием:** Zustand
- **Стили:** Tailwind CSS + shadcn/ui
- **Развертывание:** Cloudflare Pages
